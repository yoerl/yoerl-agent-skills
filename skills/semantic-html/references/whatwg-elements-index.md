# WHATWG HTML elements index

Full inventory of **conforming HTML elements** from the [WHATWG Living Standard](https://html.spec.whatwg.org/multipage/).

- **Snapshot:** 2026-11-26
- **Void** = empty element (no closing tag)
- **SVG/MathML:** listed; deep rules in separate specs
- **Obsolete:** not listed — see [obsolete.md](obsolete.md)
