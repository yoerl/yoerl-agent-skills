## 5. 상세 TC 대상

아래 `TC-*`는 `test-case` 스킬로 펼친다. 양식은 `test-case` 스킬의 `references/template-detailed.md`를 따른다.

| 예약 TC ID | 출처 TS | 펼칠 범위 (화면·권한·상태) |

| `TC-{DOMAIN}-{FLOW}-002` | `TS-{DOMAIN}-{FLOW}-002` | |
