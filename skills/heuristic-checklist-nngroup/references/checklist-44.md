# Nielsen 10 휴리스틱 — 44항 체크리스트

**NN/G 정본:** [nngroup-ten-heuristics.md](nngroup-ten-heuristics.md) · [10 heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)  
**한국어 맥락:** [heuristic-guide-ko.md](heuristic-guide-ko.md) · [m4a_ic 블로그](https://blog.naver.com/m4a_ic/222155143518)  
44항 질문 원문: Jakob Nielsen 휴리스틱 기반 체크리스트 (m4a_ic)

각 항목은 예/아니오 형태의 질문이다. 평가 시 질문 문구를 바꾸지 않는다.  
각 절 제목의 **한글 부제**는 블로그·NNG 원칙 요약이다.

## 1 Visibility of system status — 시스템 상태 가시성 (상태안내)
사용자에게 시스템의 현재 상태를 시각화 하여 보여준다.

| ID | 질문 |
|----|------|
| 1.1 | 처음 들어왔을 때 앱의 목적에 가장 부합하는 컨텐츠가 우선적으로 보이는가. |
| 1.2 | Key를 누를 때마다 제대로 된 피드백이 느껴지는가? |
| 1.3 | 각 페이지 마다 현재 선택되어 있는 아이콘의 표시가 명확하게 표현되어 있는가? |
| 1.4 | 레이아웃만 봐도 앱을 알아볼 만큼 어플리케이션만의 뚜렷한 특징이 있는가? |
| 1.5 | 적절한 텍스트와 적절한 이미지가 아름답게 배치되어 있는가? |

## 2 Match between system and the real world — 정확성 · 현실과의 일치
현실세계와 부합하도록 시스템을 설계한다.

| ID | 질문 |
|----|------|
| 2.1 | 앱 아이콘 디자인이 구체적이고 친숙한가? |
| 2.2 | 앱의 사용자가 원하는 정보를 정확히 제공하고 있는가? |
| 2.3 | 사용자가 예측하는 순서와 시스템의 작동순서가 일치하는가? |
| 2.4 | 사용시 불필요한 과정을 거치지 않는가? |
| 2.5 | 메뉴의 순서가 논리적인가? |

## 3 User control and freedom — 만족성 · 복구의 쉬움
사용자에게 적절한 통제권을 부여한다.

| ID | 질문 |
|----|------|
| 3.1 | 각 메뉴마다 인터렉션이 동일하게 제공되는가? |
| 3.2 | 각 기능을 사용하는 방법을 쉽게 기억할 수 있는가? |
| 3.3 | 사용자가 액션을 취한 후, 시스템이 작동하기 직전에 올바른 시그널을 주는가? |
| 3.4 | 앱을 사용하던 도중에 사용자 마음대로 취소 할 수 있는가? |
| 3.5 | 네트워크가 불안정한 상황에서도 앱을 사용하는데 무리가 없는가? |

## 4 Consistency and standards — 일관성과 기준
일관성과 표준성을 높인다.

| ID | 질문 |
|----|------|
| 4.1 | 똑같은 기능을 하는 버튼의 이름이 어느 화면에서나 항상 동일한가? |
| 4.2 | 세로 (또는 가로) 스크롤이 항상 일정한가? |
| 4.3 | 메뉴의 하위메뉴가 메뉴 상위 메뉴에 부합하도록 배치되어 있는가? |
| 4.4 | 각 화면마다 타이틀이 표시되어 있는가? |
| 4.5 | 한 화면의 아이콘/버튼 개수가 과하지도 부족하지도 않게 제공하고 있는가? |
| 4.6 | 타이포의 크기나 메뉴의 버튼이 적절하게 유지되고 있는가? |

## 5 Error prevention
사용자의 실수를 미연에 방지할 수 있도록 설계한다.

| ID | 질문 |
|----|------|
| 5.1 | 모든 메뉴가 논리적이고, 서로 겹치는 의미 없이 상호 구분적인가? |
| 5.2 | 메뉴의 간격을 알맞게 사용하였는가? |
| 5.3 | 앱의 검색 시스템에서 오류입력(오타)에 대한 예방책이 있는가? |
| 5.4 | 처음 접속하는 메뉴를 효과적으로 사용할 수 있도록 지시 방향이나 설명이 적절한가? |

## 6 Recognition rather than recall — 직관성
사용자가 적은 인지적 노력으로 시스템을 사용할 수 있게 한다.

| ID | 질문 |
|----|------|
| 6.1 | 검색이 필요할 때, 입력 공란이 눈에 잘 들어오는가? |
| 6.2 | 데이터의 흐름이 위쪽-왼편에서부터 시작하는가? |
| 6.3 | 각 화면마다 필요한 버튼들이 빠짐없이 배열되어 있는가? |
| 6.4 | 메뉴를 사용함에 있어 눈에 피로감을 주지 않는 시각적 흐름을 제공하고 있는가? |

## 7 Flexibility and efficiency of use — 사용의 유연성 및 효율성
시스템을 유연하게 사용할 수 있도록 한다.

| ID | 질문 |
|----|------|
| 7.1 | 옵션 정보를 편리하게 볼 수 있는가? |
| 7.2 | 내가 이전에 본 정보를 다시 검색하기 쉽게 구성되어 있는가? |
| 7.3 | 뒤로 또는 앞으로의 이동이 간편하고 쉬운가? |
| 7.4 | 옵션이나 메뉴를 나에게 맞게 수정하거나, 설정할 수 있도록 설계되었는가? |

## 8 Aesthetic and minimalist design — 심미성 · 미니멀 디자인
심미적으로 간결한 시스템을 제공한다.

| ID | 질문 |
|----|------|
| 8.1 | 가독성이 높은 텍스트와 배열을 적절하게 사용하고 있는가? |
| 8.2 | 화면에 있는 모든 정보가 꼭 필요한 정보들로만 간결하게 나열되어 있는가? |
| 8.3 | 모든 버튼들이 시각적으로나 의미적으로나 확실히 구문되는가? |
| 8.4 | 모든 버튼들이 배경과 구분되는가? |
| 8.5 | 주요 사용 컬러의 수가 적절하고 심미적으로 아름다운가? |

## 9 Help users recognize, diagnose, and recover from errors — 명확한 에러 문구
에러 발생 시 스스로 문제를 파악하고 수정할 수 있게 설계한다.

| ID | 질문 |
|----|------|
| 9.1 | 사용자가 에러를 스스로 해결할 수 있도록, 에러상활 발생시 일정기준의 가이드를 제공하는가? |
| 9.2 | 에러에 대해서 올바른 시각적 시그널이 있는가? |
| 9.3 | 에러에 대해서 올바른 사운드 시그널이 있는가? |
| 9.4 | 에러 메세지의 표현이 간결하고 명확한가? |

## 10 Help and documentation — 도움말
충분한 도움말을 제공한다.

| ID | 질문 |
|----|------|
| 10.1 | 사용 지침서를 이해하기 쉽게 시각적으로 잘 제공하는가? |
| 10.2 | 어느 페이지에서나 사용 지침서에 접근이 가능한가? |
| 10.3 | 입력창에는 예시를 이용한 도움 설명이 되어있는가? |
| 10.4 | 지침서를 원할 때 쉽게 찾을 수 있도록 가이드가 되어있는가? |
