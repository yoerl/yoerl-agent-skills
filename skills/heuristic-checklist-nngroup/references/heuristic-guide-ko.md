# 휴리스틱 평가 안내 (한국어)

**한국어 맥락:** [제이콥 닐슨의 10가지 휴리스틱 평가](https://blog.naver.com/m4a_ic/222155143518) (m4a_ic · 44항 체크리스트 출처)

## 휴리스틱 분석이란

휴리스틱 분석(Heuristic Analysis)은 전문가가 이론과 경험을 근거로 하여 일련의 규칙을 만들어 놓고, 평가 대상이 그 규칙을 얼마나 잘 지키는지 확인하는 평가 방법이다. (전문가 검토)

- 사용자 테스트·리서치 **대체 불가**
- 설계 **후** 평가도 좋지만, 원칙을 **먼저 숙지한 뒤 설계**하는 것도 권장
- 44항 체크리스트는 NNG 10원칙 + m4a_ic 글을 세분화한 점검표 ([checklist-44.md](checklist-44.md))
- 판정 시 **NN/G 정의·팁**([nngroup-ten-heuristics.md](nngroup-ten-heuristics.md))을 우선, 한글 부제는 보조

## 10가지 원칙 요약

각 원칙 아래 44항 ID를 참고해 판정한다. 영문명은 NNG 표기.

### #1 시스템 상태 가시성 — Visibility of system status

합리적인 시간 내 적절한 피드백으로 진행 상황을 알린다. 현재 상태를 시각화하고, 이전 상호작용 결과를 학습·다음 단계 결정에 쓸 수 있게 한다. 예측 가능한 상호작용은 신뢰를 형성한다.

**체크:** 1.1–1.5

### #2 정확성 · 현실과의 일치 — Match between system and the real world

사용자 언어·익숙한 단어·구문·개념을 쓴다. 정보는 자연스럽고 논리적인 순서로. 내부 용어·아이콘은 사용자에게 낯설 수 있음을 전제한다.

**체크:** 2.1–2.5

### #3 만족성 · 복구의 쉬움 — User control and freedom

실수는 흔하다. 명확한 “비상구”(취소·되돌리기)로 원치 않는 상태에서 빠져나오게 한다. 사용자가 시스템을 계속 제어하고 갇히지 않게 한다.

**체크:** 3.1–3.5

### #4 일관성과 기준 — Consistency and standards

같은 의미에 다른 단어·행동을 쓰지 않는다. 사용자는 다른 앱·웹 경험으로 기대를 형성한다. 일관성이 깨지면 인지 부하가 는다. UI 문구·인터랙션·디자인 시스템 기준을 맞춘다.

**체크:** 4.1–4.6

### #5 에러 예방 — Error prevention

오류 메시지보다 **발생 방지**가 우선. 오류가 나기 쉬운 조건 제거, 실행 전 확인 옵션. 실수로 위험한 액션 시 충분히 인지시킨다 (예: 경고 없이 작성 중 데이터 소실).

**체크:** 5.1–5.4

### #6 직관성 — Recognition rather than recall

별도 학습 없이 기능을 인식하게 한다. 검색만 보여 주기보다 연관 태그·연상 이미지 등 맥락 정보를 함께 준다.

**체크:** 6.1–6.4

### #7 사용의 유연성 및 효율성 — Flexibility and efficiency of use

초보·숙련 사용자 모두 배려. 자주 쓰는 메뉴·순서 변경·단축 경로 등으로 인지 부하를 줄인다.

**체크:** 7.1–7.4

### #8 심미성 · 미니멀 디자인 — Aesthetic and minimalist design

관련 없거나 거의 불필요한 정보는 제외. 추가 정보 단위는 핵심과 경쟁해 가시성을 떨어뜨린다. “심심한 디자인”이 아니라 **필수에 집중**하고 시각 요소가 사용자 목표를 지원하는지 본다.

**체크:** 8.1–8.5

### #9 명확한 에러 문구 — Help users recognize, diagnose, and recover from errors

일반 언어(코드 남발 없음), 문제를 정확히 표시, 건설적 해결책·시각적 처리. 쉽고 명확한 표현과 빠른 회복 경로.

**체크:** 9.1–9.4

### #10 도움말 — Help and documentation

이상적으로는 추가 설명 없이 완료 가능. 필요 시 **간결**하고 **구체적 단계**의 문서. 어디서나 찾기 쉬워야 한다.

**체크:** 10.1–10.4
